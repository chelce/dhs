📋 Analogy Relationship Types - Quick Reference

Part/Whole
Wheel : Car :: Page : Book
One item is part of the larger whole
Synonyms
Happy : Joyful :: Sad : Melancholy
Words with similar meanings
Antonyms
Hot : Cold :: Light : Dark
Words with opposite meanings
Function
Hammer : Nail :: Pen : Paper
Tool used with specific object
Cause/Effect
Rain : Flood :: Study : Knowledge
One thing leads to another
Category/Example
Fruit : Apple :: Sport : Soccer
General category and specific example
