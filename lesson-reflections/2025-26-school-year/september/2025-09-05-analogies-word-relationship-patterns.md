# Analogies + Word Relationship Patterns Lesson Plan
**Date**: September 5, 2025  
**Classes**: 9th Grade ELA (CP, Honors, AP)  
**Duration**: 74 minutes  
**Unit**: Foundation Skills & Pattern Recognition  

## Learning Objectives
Students will:
- Identify relationship types in analogies (part/whole, synonym/antonym, cause/effect, etc.)
- Create new analogies using specific relationship patterns
- Recognize that analogies follow predictable patterns that can be applied systematically
- Work collaboratively to solve pattern-based problems

## Materials Needed
- **All Tiers**: Analogy relationship pattern reference cards, whiteboard/vertical surfaces
- **Easy Tier**: Color-coded visual relationship cards, pre-made analogy examples
- **Medium Tier**: Relationship sorting bins, analogy creation templates
- **Hard Tier**: Complex relationship challenge cards, sentence integration examples

## Class Structure (74 minutes)

### Opening Activity (7 minutes)
**Quick Analogy Warm-Up**: Display 3 analogies on board, students discuss in pairs what makes them work
- Example: "Book is to library as car is to ____"
- Students share out relationship they identified

### Mini-Lesson: Pattern Introduction (15 minutes)
**Direct Instruction**: Introduce 6 main analogy relationship types with examples
1. **Part/Whole**: Wheel : Car :: Page : Book
2. **Synonyms**: Happy : Joyful :: Sad : Melancholy  
3. **Antonyms**: Hot : Cold :: Light : Dark
4. **Function**: Hammer : Nail :: Pen : Paper
5. **Cause/Effect**: Rain : Flood :: Study : Knowledge
6. **Category/Example**: Fruit : Apple :: Sport : Soccer

### Task Work Time (45-50 minutes)
Students self-select difficulty tier and work in collaborative groups on vertical surfaces

### Wrap-Up & Reflection (5-7 minutes)
Groups share one interesting pattern they discovered or created

## Three-Tier Task Structure

### Easy Tier (On-Ramp Level)
**Target**: Students match analogies to relationship types using visual supports

**Task**: "Analogy Detective - Pattern Matching"
1. Receive 12 pre-written analogies on cards
2. Sort them into 6 relationship type bins (color-coded)
3. Use visual reference chart showing relationship types with pictures
4. Check answers with partner before final submission

**Success Criteria**:
- Correctly sorts 8/12 analogies (67%)
- Can explain relationship using provided vocabulary
- Works collaboratively throughout activity

**Economy Integration**: Earn $3 per correct sort, $1 bonus for perfect collaboration

### Medium Tier (Grade-Level + Scaffolding)
**Target**: Students categorize analogies AND create 2 new examples per relationship type

**Task**: "Pattern Builder"
1. Sort 18 analogies into 6 relationship categories (no color coding)
2. Create 2 original analogies for each relationship type (12 total)
3. Use analogy template: "_____ : _____ :: _____ : _____"
4. Partner must verify that new analogies follow the pattern correctly

**Success Criteria**:
- Correctly sorts 14/18 analogies (78%)
- Creates at least 10/12 new analogies that follow patterns
- Can explain why their analogies work

**Economy Integration**: Earn $5 per relationship category completed, $2 bonus for creative examples

### Hard Tier (Above Grade-Level)
**Target**: Students work with complex relationships and integrate analogies into sentences

**Task**: "Advanced Pattern Master"
1. Identify relationships in 20 complex analogies (including degree, location, worker/tool)
2. Create 3 original analogies per relationship type using sophisticated vocabulary
3. Write 2 sentences that integrate analogies to explain concepts
4. Challenge: Create an analogy chain (A:B::C:D::E:F)

**Success Criteria**:
- Correctly identifies relationships in 16/20 analogies (80%)
- Creates sophisticated analogies with advanced vocabulary
- Successfully integrates analogies into explanatory writing
- Demonstrates understanding of analogy chains

**Economy Integration**: Earn $8 per advanced relationship mastered, $5 bonus for analogy chains

## Cultural Responsiveness Elements
- Include analogies using foods from Hispanic/Brazilian cultures
- Reference family structures and community roles familiar to students
- Use Spanish/Portuguese cognates when introducing relationship vocabulary
- Honor cultural knowledge as academic strength

**Example culturally responsive analogies**:
- "Abuela : Wisdom :: Teacher : Knowledge"
- "Quinceañera : Celebration :: Graduation : Achievement"
- "Tamale : Corn :: Brigadeiro : Chocolate"

## Assessment Strategy

### Formative Assessment (During Activity)
- Teacher circulation notes on student reasoning
- Peer explanation quality during collaboration
- Self-selection of appropriate difficulty tier

### Summative Assessment Options (Next Class)
**Skill Check A**: Given 10 analogies, identify the relationship type (5 minutes)
**Skill Check B**: Create 3 analogies using specified relationship types (8 minutes)

## Differentiation Support

### ELL Accommodations
- Provide relationship vocabulary in both English and Spanish
- Allow use of translation tools for analogy creation
- Pair with English-proficient partners when beneficial

### Special Needs Modifications
- Reduce number of analogies for processing concerns
- Provide extra time for completion
- Allow verbal explanation instead of written for relationship types

### Advanced Extensions
- Challenge to create analogies using academic vocabulary from other subjects
- Research cultural analogies from different languages
- Create analogies that work in both English and Spanish
